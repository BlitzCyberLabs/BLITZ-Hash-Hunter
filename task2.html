TASK 02 / CRACK PASSWORD HASHES

Offline password audit

Download the synthetic credential export and supplied wordlist. Use John the Ripper or Hashcat in Kali Linux to recover all four passwords in the file. The credential file contains mixed formats (MD5 and SHA-1), so separate the records by hash format before cracking.

↓ leaked_credentials.txt ↓ novatech_wordlist.txt
kali@analyst:~$ john --format=Raw-MD5 --wordlist=novatech_wordlist.txt leaked_credentials.txt
kali@analyst:~$ john --format=Raw-SHA1 --wordlist=novatech_wordlist.txt leaked_credentials.txt
kali@analyst:~$ john --show --format=Raw-MD5 leaked_credentials.txt && john --show --format=Raw-SHA1 leaked_credentials.txt
